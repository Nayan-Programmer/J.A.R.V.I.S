# J.A.R.V.I.S — Local Setup Guide

**Just A Rather Very Intelligent System**  
Runs fully locally at `http://localhost:8000`

---

## Quick Start

### 1. Install Python dependencies

```bash
cd jarvis
pip install -r requirements.txt
```

> **Note:** The first run downloads sentence-transformer models (~400 MB). Subsequent starts are fast.

### 2. Configure API keys

Your `.env` file is already set up. If you need to reset it, copy `.env.example`:

```bash
cp .env.example .env
# Then fill in your GROQ_API_KEY
```

Required:
- `GROQ_API_KEY` — get free at https://console.groq.com

Optional:
- `TAVILY_API_KEY` — enables real-time web search (https://tavily.com)

### 3. Run the server

```bash
python run.py
```

Then open **http://localhost:8000** in your browser.

## What's New

### Vision (Camera Analysis)
- Click the **camera icon** in the chat bar to open your webcam
- Ask Jarvis "What do you see?" or any question — it will analyze the live frame
- Uses Groq's **llama-3.2-11b-vision-preview** model
- Automatic fallback to `llama-3.2-90b-vision-preview` if needed

### Task Execution
- **Open websites:** "Open YouTube", "Go to GitHub"
- **Play music:** "Play Shape of You on YouTube" → opens YouTube search
- **Search:** "Search Google for Python tutorials"
- **Generate images:** "Draw a sunset over the ocean" → uses Pollinations AI (free, no key needed)
- **Write content:** "Write an essay about AI" → background task, opens in result viewer

### Background Tasks
- Long tasks (image generation, content writing) run in the background
- A progress card appears in chat — click **Open in new tab** to see the result
- Results shown in `viewer.html` with download / copy options

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/chat/jarvis/stream` | **Main endpoint** — SSE streaming for all features |
| `GET`  | `/tasks/{task_id}` | Poll background task status |
| `GET`  | `/health` | Service health check |
| `POST` | `/chat` | Legacy non-streaming chat |
| `POST` | `/chat/realtime` | Legacy realtime chat |
| `GET`  | `/chat/history/{session_id}` | Get session history |
| `GET`  | `/docs` | Auto-generated API docs |

## Troubleshooting

**Backend won't start:**  
- Make sure Python 3.10+ is installed
- Run `pip install -r requirements.txt` again
- Check `.env` has a valid `GROQ_API_KEY`

**Camera not working:**  
- Allow camera permission in your browser
- Use Chrome or Edge (best WebRTC support)
- Camera requires HTTPS or localhost

**Image generation slow:**  
- Images are generated by Pollinations AI (free external service)
- First generation can take 10-30 seconds

**Rate limit error:**  
- Your Groq key hit its daily limit
- Add more keys as `GROQ_API_KEY_2`, `GROQ_API_KEY_3` in `.env`
